# ASSIST · XRAIC — Prototipo visual

Este repositorio público contiene únicamente una interfaz de demostración, con pacientes y expedientes **completamente ficticios**. No contiene información clínica real y no debe utilizarse para la atención de pacientes.

La aplicación estática permite revisar visualmente Consulta, Reporte clínico, Analítica, Historial y Pruebas. No se conecta a SQL, Ollama ni a servicios médicos.

Para publicar: Settings → Pages → Deploy from a branch → main → /(root).

El proyecto clínico original permanece en un repositorio privado independiente.
