# ASSIST · XRAIC — Prototipo de interfaz

Prototipo de diseño visual y UX con cinco pantallas: Consulta, Reporte clínico, Analítica, Historial y Pruebas.

**Contenido 100 % sintético.** Los nombres, expedientes y narraciones son ficticios y se usan únicamente para evaluar el diseño. No se conecta con SQLite, Ollama ni un sistema clínico real y no debe usarse para decisiones médicas.

## Archivos

- `index.html`: entrada a la interfaz.
- `css/base-v3.css`: estilos de la referencia visual v3.
- `css/adjustments.css`: ajustes de interfaz.
- `js/`: navegación, componentes y pantallas.
- `data/`: casos completamente ficticios.

## GitHub Pages

Ir a **Settings → Pages**, elegir **Deploy from a branch**, rama **main** y carpeta **/(root)**, y guardar.

La dirección prevista es `https://danielr850.github.io/Interfaz-xraic/`, pero solo funcionará cuando GitHub Pages esté activado y la publicación concluya.

El repositorio original de la aplicación clínica permanece privado y separado.
